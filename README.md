# groupingsweb

Website for the **Groupings** iOS app — HTML, CSS, JavaScript, and static assets.

## Structure

```
.
├── index.html      # landing page
└── assets/         # images, css, js, fonts
```

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deployment

Static site — can be hosted on GitHub Pages, Netlify, Cloudflare Pages, or any
static host. Point the custom domain at the host once purchased.
